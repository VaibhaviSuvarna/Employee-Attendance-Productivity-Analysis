#Employee Attendance & Productivity Analysis | Power BI

## Project Overview

The **Employee Attendance & Productivity Analysis** project is an interactive Power BI dashboard designed to analyze employee attendance, leave patterns, overtime hours, task completion, and productivity performance.

The dashboard presents key performance indicators (KPIs), visual comparisons, and interactive filters to help users explore workforce performance across employees, departments, and cities.

## Project Objectives

- Monitor overall employee attendance performance.
- Track total leave days and overtime hours.
- Analyze tasks completed by individual employees.
- Compare productivity scores across departments.
- Present workforce metrics through an interactive dashboard.

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Data Modeling
- DAX Measures and Aggregations
- Data Visualization
- Interactive Slicers and Filtering
- Business Intelligence and KPI Reporting

## 📈 Dashboard Features

### 1. Key Performance Indicators

The dashboard includes five KPI cards:

- **Attendance Rate:** Tracks the overall attendance rate.
- **Total Leave Days:** Displays the total recorded leave days.
- **Total Overtime Hours:** Measures accumulated overtime hours.
- **Total Tasks Completed:** Shows the total number of completed tasks.
- **Average Productivity Score:** Displays the average productivity score.

### 2. Employee Attendance Analysis

A column chart compares the number of present days across employees, helping users examine attendance differences.

### 3. Department Productivity Analysis

A column chart compares productivity scores across departments to support departmental performance analysis.

### 4. Employee Task Completion Analysis

A column chart compares completed tasks by employee, providing a view of individual task completion.

### 5. Department Overtime Analysis

A column chart compares overtime hours across departments to help identify differences in overtime distribution.

### 6. Interactive Filtering

The dashboard includes slicers for:

- Department
- City
- Employee

These filters allow users to explore the available data for selected employees, locations, and departments.

## 📊 Business Questions Addressed

This project helps explore questions such as:

- What is the overall employee attendance rate?
- How many leave days and overtime hours have been recorded?
- Which employees have recorded more present days?
- How do productivity scores vary across departments?
- Which departments account for more overtime hours?
- How do the dashboard metrics change when filtering by employee, department, or city?

## 💡 Business Value

The dashboard demonstrates how business intelligence can help organizations:

- Monitor workforce attendance.
- Track employee productivity indicators.
- Understand leave and overtime patterns.
- Compare employee and departmental performance.
- Explore workforce data using interactive filters.
- Support data-informed workforce planning.

The visualizations support performance monitoring and further investigation. They do not, by themselves, establish the causes of differences in employee productivity or attendance.


## 🚀 How to Use

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open `Employee_Attendance_Productivity_Analysis.pbix`.
4. Review the KPI cards and charts.
5. Use the Department, City, and Employee slicers to explore the data.
6. If prompted, configure the data source and refresh the report as required.
